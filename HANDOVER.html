3. What this system does

  • A digital QR menu for Patel RESTAURANT (33 categories, 304 dishes).
  • Customers scan a QR code → open the menu on their phone → browse dishes with photos, prices, categories.
  • No ordering, no cart, no payment — view-only menu.
  • Admin panel to manage categories, dishes, images, settings, users, QR stands, backups.
  • All changes reflect live on the customer menu instantly.

4. How to use the Admin Panel

Login

Open the Admin Login URL above → enter email & password → click Login (eye icon shows/hides password).

Dashboard

Shows counts: categories, dishes, images, missing images. Click any stat card to jump to that section.

Menu Categories (/admin/categories)

  • Add: "+ Add Category" → name → save.
  • Edit: click category → change name/image → Save.
  • Reorder: drag ☰ handle → "Save Order".
  • Delete: Delete (removes category + its dishes).

Menu Items / Dishes (/admin/items)

  • Filter by category or search by dish name.
  • Edit: "Edit" → name, price, category, position, image → "Save Changes".
  • Add: "+ Add New Item" → name, category, price, image → Add.
  • Delete: Delete.
  • Reorder: drag within category → "Save Order".
  • Upload image: in edit modal, pick file → "Upload" → "Save Changes".

Media Library (/admin/media)

  • View all dish images (baked-in + uploaded).
  • Search by dish name or filename; filter by category/status; sort.
  • Replace: Replace → pick new file → dish image updates everywhere automatically.
  • Delete: Delete (dish shows placeholder).
  • Bulk delete: select multiple → "Delete Selected".
  • Upload new: "Upload" button at top.

Restaurant Settings (/admin/settings)

  • Change name, phone 1, phone 2, logo. Upload a new logo.
  • Developer credit is locked (not editable).

User Management (/admin/users) — Admin only

  • Create users (admin or limited). Edit name, email, role, password. Delete (cannot delete last admin).

QR Code & Stands (/admin/qrcode)

  • Preview the table stand card. Enter Table Number for custom cards.
  • Download PNG — full high-res stand design.
  • Download PDF — print-ready A4.
  • Print — prints only the stand card.
  • Place printed card in acrylic table stands.

Backup & Restore (/admin/backup)

  • Create Backup: downloads ZIP with all menu data + images.
  • Restore: upload a backup ZIP to restore everything.

My Account (/admin/account)

Change your own name, email, password.

5. Customer flow

  1. Customer scans the QR code on the table.
  2. The digital menu opens in their browser.
  3. They browse categories and dishes, see photos and prices.
  4. They can tap a phone number to call the restaurant.
  5. No ordering or payment — view only.
